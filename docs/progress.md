## M1 可玩原型 ✅ (2026-09-21)

**做了什么**
- Vite + three.js 脚手架；程序化城市（8×8 街区、Canvas 路网地面纹理、低模塔楼 + 霓虹描边、公园/工地、路口霓虹桩 InstancedMesh）
- 机器人骑手驾驶：W/S 加减速、A/D 转向（低速转向权重衰减）、Shift 加速、建筑 AABB 碰撞推出+减速、压弯倾斜
- 订单循环：报价池自动生成 → Enter 接单 → 取餐点 E 取餐 → 送达点 E 交付 → 计时 + 收入（准时加成/超时折扣）
- HUD：时间/收入/订单倒计时/报价列表/交互提示/时速；WebAudio 合成音效（引擎、接单、取餐、到账、碰撞）

- `window.__game` 调试句柄 + Playwright e2e（完整 chromium 二进制无头模式）

**怎么验证的**
- `npm run build` 通过；`node test/e2e.mjs m1` 10 项全 PASS：冷启动、W 加速且位移沿车头方向(fwdDot=1.00)、A 左转 Δheading=1.98、接单→取餐→送达全流程、收入 ¥0→¥6.8、时钟推进、无控制台报错
- 截图人工检查：城市霓虹夜景、HUD、取餐标记、到账 toast 均正常渲染

## M3 系统层 ✅ (2026-09-21)

**做了什么**
- 8 小时工作日 + 3 种自选班次（早班/高峰班/夜班），饭点高峰（11–13、18–20）：单更密、报酬 ×1.35
- 昼夜光照：9 个关键帧插值天空/雾/太阳/半球光，太阳方位随时间起落，夜班覆盖真·夜晚
- 温水煮青蛙难度：近 6 单平均用时比驱动 slackScale 在 0.72–1.25 间渐进调整
- 随机事件 9 种（封路/查车/转让/顺路单/酸雨/堵车/电池告警/无人机/小费），数据驱动 + 冷却 + 权重
- 知识锁 7 条，按送达数或经历事件解锁，效果统一汇总到 game.mods
- 电池系统：冲刺耗电、低电量限速、两个路口充电点闪充；雨天打滑（位移方向滞后车头）
- 日结算界面：收入/准时率/事件回顾/知识数，R 键开新的一天
- 修 bug：`setMinutes` 越出班次会触发日结导致后续测试全挂 —— 已修正测试选夜班

**怎么验证的**
- `node test/e2e.mjs m3` 30 项全 PASS：正午/夜晚光照差异（sunI 1.15 vs 0.28）、高峰判定、封路/堵车/无人机/转让/查车事件逐一触发断言、查车冻结与放行、冲刺耗电 60→55.5、难度 1→0.88 收紧、知识解锁（送达数 + 事件两类条件）、24:00 日终结算 → R 开新一天、无报错
- 截图人工检查：高峰 HUD、电池条、日结算面板（收入/准时率/事件回顾）
